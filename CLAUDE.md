# Continuing this port

Read [AGENT-README.md](AGENT-README.md), [CONTRIBUTING.md](CONTRIBUTING.md),
[GAMEPLAY-STATUS.md](GAMEPLAY-STATUS.md) and
[github issues/README.md](github%20issues/README.md) before making changes.

The owner now accepts backgrounds where the corresponding Legacy4J menu
has them. This supersedes the earlier blanket clear-background requirement.
Use [Reference-Images/](Reference-Images/) and the matching source screen:
retain panels where shown and keep genuinely clear screens clear. Do not
apply one background treatment to every menu.
Keep issue handling, attribution, live verification and publishing consistent
with the linked workflow. Identify yourself as Claude with your actual model
when posting; do not copy an earlier agent's identity.

Follow the [README progress tracking rules](README.md#port-progress-checklist).
Update the checklist after every implementation session, using `[ ]`, `[~]`,
`[x]`, `[!]` and `[?]` as defined there. `[x]` requires a working, tested
in-game feature. Prefer Horizon's modding API.
